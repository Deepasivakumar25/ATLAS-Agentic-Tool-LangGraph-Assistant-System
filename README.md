# ATLAS — Agentic Tool & LangGraph Assistant System

ATLAS (Agentic Tool & LangGraph Assistant System) is a tool-using AI assistant built with LangGraph and a Groq-hosted Large Language Model (LLM). The project demonstrates how an LLM can decide when to use external tools, execute those tools through a LangGraph workflow, and continue the conversation using the returned results.

## Features

- LLM-based tool selection
- Tool calling with LangGraph
- Wikipedia search for general knowledge
- Google Search using Serper for web search
- Calculator tool for arithmetic expressions
- Conditional routing between the chatbot and tools
- Conversation memory using LangGraph `MemorySaver`
- Interactive command-line chat application
- Same workflow available in both Jupyter Notebook and Python formats

## Agent Workflow

```text
User Input
    ↓
Chatbot / LLM
    ↓
Does the LLM need a tool?
   ↙              ↘
 Yes               No
  ↓                 ↓
ToolNode          Final Answer
  ↓
Execute Tool
  ↓
Return Tool Result
  ↓
Chatbot / LLM
  ↓
Final Answer
```

## Tools Used

### 1. Wikipedia Tool

The Wikipedia tool retrieves information from Wikipedia when the LLM determines that a Wikipedia lookup is useful.

### 2. Google Search Tool

The Google Search tool uses the Serper API to retrieve web search results when the LLM needs current or searchable information.

### 3. Calculator Tool

The calculator tool uses `simpleeval` to evaluate mathematical expressions such as:

```text
25 * 4 + 10
```

The LLM can select the calculator instead of trying to perform the calculation itself.

## Memory

ATLAS uses LangGraph's `MemorySaver` as an in-memory checkpointer.

A `thread_id` is used to maintain the conversation state for the interactive session. This allows the graph to preserve previous messages within the same conversation while the application is running.

The memory is intended for learning and demonstration purposes. It is not a persistent database and the conversation state is not designed to survive application restarts.

## Getting Started

Clone the repository and install the required dependencies:

```bash
git clone https://github.com/Deepasivakumar25/ATLAS-Agentic-Tool-LangGraph-Assistant-System.git
cd ATLAS-Agentic-Tool-LangGraph-Assistant-System
pip install -r requirements.txt
```

Set the required environment variables before running the Python application:

```bash
SERPER_API_KEY=your_serper_api_key
GROQ_API_KEY=your_groq_api_key
```

On Windows PowerShell:

```powershell
$env:SERPER_API_KEY="your_serper_api_key"
$env:GROQ_API_KEY="your_groq_api_key"
```

Run the application from the project root:

```bash
python -m src.main
```

The notebook can also be opened in Jupyter or Google Colab for step-by-step experimentation.

## LangGraph Structure

The graph contains two main nodes:

```text
START
  ↓
chatbot
  ↓
tools_condition
  ├── tools ──→ chatbot
  └── END
```

The `chatbot` node sends the conversation to the LLM. If the LLM requests a tool, LangGraph routes the request to the `ToolNode`. After the tool is executed, the result is returned to the chatbot node so the LLM can generate the final response.

## Purpose

This project is a hands-on learning implementation focused on understanding **LangGraph, tool calling, agent workflows, conditional routing, and conversation memory**. It demonstrates the basic structure required to build an agent that can decide when to use tools rather than relying only on the LLM's internal knowledge.
